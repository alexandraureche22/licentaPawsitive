# AdoptăCuDrag — Platformă de Adopții Animale

Aplicație web full-stack pentru gestionarea adopțiilor de animale, cu quiz de compatibilitate, chat, donații, statistici și panou admin.

## Tehnologii
- **Frontend:** React, Redux, React Router, Recharts, Leaflet, Lucide React
- **Backend:** Express, Sequelize, SQLite, JWT, Bcrypt, Multer
- **Build:** Vite

## Instalare

### Client
```bash
npm install
npm run dev
```

### Server
```bash
cd server
npm install
npm run preload
npm start
```
